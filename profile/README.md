# 破滅派 / Hametuha INC.

> 後ろ向きのまま前へ進め！

破滅派は、オンライン文芸誌 [破滅派](https://hametuha.com) を運営する小さな出版社です。
誰でも小説を投稿・公開できるWebサイトと、紙・電子書籍の出版を手がけています。
サイトは WordPress で動いており、そこで生まれた機能をプラグインやライブラリとしてオープンソースで公開しています。

Hametuha is a small Japanese publisher running an online literary magazine on WordPress.
We open-source the plugins and tools born from building it.

## WordPress プラグイン

[WordPress.org](https://profiles.wordpress.org/hametuha/) で公開しているプラグインです。

| プラグイン | 概要 |
|---|---|
| [Gianism](https://github.com/hametuha/gianism) | Facebook・Google・X などのSNSアカウントでログインできるようにする |
| [WP-Yomigana](https://github.com/hametuha/wp-yomigana) | エディタからルビ（ふりがな）を挿入する |
| [Never Let Me Go](https://github.com/hametuha/never-let-me-go) | ユーザーが自分で退会できるようにする |
| [Anyway Feedback](https://github.com/hametuha/anyway-feedback) | 読者からのフィードバックを集める |
| [Hamazon](https://github.com/hametuha/wp-hamazon) | Amazon・DMM などのアフィリエイトリンクを挿入する |
| [HameSlack](https://github.com/hametuha/hameslack) | WordPress と Slack を連携する |
| [Hamail](https://github.com/hametuha/hamail) | SendGrid 経由でメールを送信する |
| [HameThread](https://github.com/hametuha/hamethread) | シンプルなフォーラム（掲示板）を設置する |
| [HametuPack](https://github.com/hametuha/hametupack) | Jetpack に小さな便利機能を追加する |
| [hamecache](https://github.com/hametuha/hamecache) | Cloudflare を使ったページキャッシュ |
| [Chiramise](https://github.com/hametuha/chiramise) | コンテンツの一部を会員限定にする |

## 出版のための道具

| リポジトリ | 概要 |
|---|---|
| [hamepub](https://github.com/hametuha/hamepub) | ePub を生成する PHP ライブラリ |
| [epub-style](https://github.com/hametuha/epub-style) | 電子書籍向けの HTML スタイル |
| [novel](https://github.com/hametuha/novel) | 小説プロジェクトを管理する CLI |
| [indesign-tagged-text](https://github.com/hametuha/indesign-tagged-text) | テキストを InDesign タグ付きテキストに変換する |
